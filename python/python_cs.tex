\section*{Sintaxis básica}
\begin{multicols}{2}
    \begin{lstlisting}
    x = 5
    print(x)

    if __name__ == "__main__":
        x = 5
        print(x)
   
\end{lstlisting}
\columnbreak

La diferencia entre el script directo y el que está dentro del if es la prioridad de ejecución.
El código dentro del if sólo se ejecuta si se corre directamente el archivo, más no lo hará si el archivo se una importación.  
\end{multicols}
